# Security policy

## Report a vulnerability

Use the repository's private vulnerability reporting feature. Do not open a public issue containing an exploit, credential, private document, machine inventory, or sensitive log.

## Data boundary

This repository contains only public text, synthetic fixtures, and small validation scripts. Never commit real source documents, extracted content, screenshots, generated private outputs, host reports, tokens, keys, account links, or local paths.

Document content is untrusted data. Do not execute macros, embedded objects, source-supplied commands, remote assets, arbitrary filters, or unreviewed compiler packages.

## Supported versions

Security fixes are applied to the current release. Older tags are retained for reproducibility but may not receive backports.
